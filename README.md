# HexaScale IoT Landing

Landing page สำหรับโปรเจกต์ **HexaScale IoT** สไตล์ใหม่ ๆ เน้นดีไซน์แปลกใหม่ อ่านง่าย และคุยเรื่อง IoT แบบมืออาชีพ

## โครงสร้าง
- `index.html` หน้าเว็บหลัก
- `styles.css` สไตล์ธีมมืด + เอฟเฟกต์อะโรร่า
- `script.js` เอฟเฟกต์เล็กๆ และฟอร์มทดสอบรับคอนแทค
- `self-profile.md` ข้อมูลตัวตนแบรนด์ HexaScale
- `agent.md` ไฟล์อ้างอิงซอร์สเว็บหลัก

## รันหน้าเว็บเร็วๆ
เปิดไฟล์ `index.html` ใน browser ได้ทันที หรือใช้เซิร์ฟเวอร์ง่ายๆ:

```bash
git clone <repo>
cd <repo>
python -m http.server 4173
```

แล้วเปิด `http://localhost:4173`
